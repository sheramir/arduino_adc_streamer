# guides

User-facing guides for configuring and using current application features.

- `configuration/ARRAY_CONFIGURATION_GUIDE.md` — the `array_layout` sensor configuration type: grid model, sensor IDs, MUX/channel assignment, storage, Sensor-tab workflow, validation, troubleshooting.
- `heatmap/HEATMAP_README.md` — the Heatmap tab: modes, input requirements, controls, persisted settings, performance notes.
- `heatmap/heatmap_parameters.xlsx` — heatmap parameter workbook.
